# Credits

reTS is a fan-made reconstruction of The Specialists 3.0. It is not affiliated with or endorsed by the
original team. Everything below comes from the files TS 3.0 itself ships (`recovered/ts3-linux/ts/`);
each entry names its source. Where a file names nobody, the entry says so instead of guessing.

## The Specialists

- **Morfeo**: creator of The Specialists, lead developer (CHANGELOG.txt sections; player models below;
  original ts_lobby, ts_lobbyduel textures).
- **Vino** (Jorge Rodriguez): developer, TS 3.0 code (CHANGELOG.txt sections; liblist.gam).
- **Omega**: player model skins (agent, gordon, hitman, laurence, merc, seal readmes).
- **Supernovae**: head skins for agent and hitman.
- **John_Matrix**: the coat on gordon and laurence.
- **Sjet vs Kerrigan**: many custom pistol animations and a fixed Gordon model (CHANGELOG.txt, special
  thanks).
- **Podunkian**: the MP5SD stock attack animation (CHANGELOG.txt, special thanks).

The weapon models, weapon sounds, sprites and HUD art ship without a readme naming their authors.

## Terms stated in the shipped readmes

Recorded as the files state them, for anyone redistributing the content:

- **Player models** (Morfeo's six, Castor Troy): "Don't reproduce or modify the model without permission,
  don't use it in a total conversion/mod without permission."
- **ts_awaken, ts_casa, ts_central, ts_heresy**: distribute only with the readme unmodified, "ONLY over
  the Internet and/or BBS systems", and not "on any CD or ... in any way without my (written) permission".
- **ts_lobby (BIDO)**: ask permission to reuse BIDO's models, textures and sounds in other maps.
- **Morning Mountains**: non-commercial use with credit.
- **ts_wyndham**: credit the author and distribute the readme with the map; textures are for
  non-profit, credited use.
